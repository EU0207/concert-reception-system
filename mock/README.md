## 起動方法

`mock/index.html` をブラウザーで開く。外部接続と依存関係の導入は不要。PC表示に加えて、ブラウザーの開発者ツールでスマートフォン幅にして確認する。

## 操作の流れ

1. 「公演準備」で来場者管理、会場席編集、席配置、チケット準備を操作する。
2. 「スタッフ・端末」で招待から事前準備まで進める。
3. 「当日受付」で受付カメラ、結果、連絡、会場席を確認する。
4. ヘッダーの役割、通信状態、未読数を切り替えて表示の違いを確認する。
5. 未保存のまま別画面へ移動し、3つの離脱選択肢を試す。

ブラウザーを再読み込みすると初期状態に戻る。カメラ、Firebase、認証、同期、実ファイル出力は接続していない。QR読取り、端末停止、締め、削除は画面操作のみを再現する。
