## 起動方法

PCでは`mock/index.html`をブラウザーで開く。外部接続と依存関係の導入は不要。

実際のスマートフォンで確認する場合は、PCとスマートフォンを同じ家庭内ネットワークへ接続する。PCでPowerShellを開き、リポジトリのルートから次を実行する。

```powershell
node mock/server.cjs
```

PCで`ipconfig`を実行してプライベートIPv4アドレスを確認する。スマートフォンのブラウザーで`http://＜PCのIPv4アドレス＞:8765`を開く。例：PCのアドレスが`192.168.0.23`なら`http://192.168.0.23:8765`。サーバーは起動中だけ利用でき、終了するにはPowerShellで`Ctrl+C`を押す。Windowsファイアウォールから確認が出た場合は、信頼できるプライベートネットワークでの利用だけを許可する。接続できない場合は、端末が同じネットワークにあることと、PC側のファイアウォール設定を確認する。

このサーバーはモックの静的ファイルだけを配信する。Firebaseへ公開しない。スマートフォンでも実カメラによるQR読取りは行わず、画面上の架空判定ボタンで操作を確認する。

## 操作の流れ

1. 「公演準備」で来場者管理、会場席編集、席配置、チケット準備を操作する。来場者管理では名前を押して詳細を開き、購入者名の修正と不参加への切替を試す。席配置済みなら解除を確認する。発行済みの場合は二度確認する。席配置では入金確認済み・入金未確認・来場予定の未配置全員を切り替えて候補を確認する。
2. 来場者管理の「大量の名簿を試す」で500件の架空行を追加し、50件・100件の表示とページ切替を確認する。購入者名を押すと、その行の情報をまとめて確認できる。
3. チケット準備では不参加者が一覧に出ないことを確認する。「入金済み」などの緑色の固定項目と確認用項目を見比べ、「確認用チェック項目を管理」で項目の追加、名前変更、削除を試す。削除した項目を戻す操作は設けない。再読み込みで初期状態へ戻る。
4. 「スタッフ・端末」で招待から事前準備まで進める。
5. 「当日受付」で受付カメラ、結果、連絡、会場席を確認する。
5. ヘッダーの役割、通信状態、未読数を切り替えて表示の違いを確認する。
6. 未保存のまま別画面へ移動し、3つの離脱選択肢を試す。

ブラウザーを再読み込みすると初期状態に戻る。カメラ、Firebase、認証、同期、実ファイル出力は接続していない。QR読取り、端末停止、締め、削除は画面操作のみを再現する。不参加時の発行状態の解除は表示上の操作であり、実際のQR無効化と履歴保存は行わない。
