## 確認方針

- 依頼者または依頼者が指定する管理者権限を持つ利用者が確認する。
- 500人分の架空データ、最大10人の架空利用者、6つ以上の独立した受付環境を使用する。端末固有の確認には最大3台の実機を使用する。
- オンライン、通信切断、最初から通信がない状態、復旧・統合を含める。
- 判定は `未実施`、`合格`、`不合格` のいずれかとし、実施日、確認者、証跡は将来のテスト記録へ残す。
- 正式要件化した `RQ-001`～`RQ-006` は本書の受入対象に含める。未決定事項の確定により期待結果が変わる場合は、実装前に本書を更新する。
- Issue #6の調査・PoC結果は確認方法と期待結果へ反映済みである。PoCの合格は限定範囲の技術証跡であり、本番の最終受入判定とは区別する。
