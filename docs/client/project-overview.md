## 背景

コンサート当日の受付では、来場者の確認、受付済みかどうかの把握、来場状況の集計を正確かつ円滑に行う必要があります。

## 目的

- QRコードを利用して受付作業を簡略化する。
- 来場者ごとの受付状態を正確に管理する。
- 公演当日の来場状況を関係者が確認できるようにする。
- 要件、設計、テスト、運用上の判断を追跡可能にする。

## 期待する効果

- 受付担当者の確認作業を削減できる。
- 二重受付や受付状況の記録漏れを防止できる。
- 公演運営に必要な来場状況を把握しやすくなる。

## 対象範囲

対象となる業務と機能は、依頼者への確認を通じて要件定義書で確定します。

## 対象外

現時点では未確定です。要件定義の中で、今回対応しない業務と機能を明示します。

## 前提と制約

- 実際の会場環境、利用端末、通信環境は確認中です。
- システム構成、使用技術、公開方法は未決定です。
- 個人情報の取扱いと保存期間は、依頼者への確認後に決定します。
