# 打合せ記録

## この文書について

| 項目 | 内容 |
|---|---|
| 目的 | 打合せで確認した事実、決定事項、宿題事項を追跡可能にする |
| 主な読者 | 依頼者、開発担当者 |
| 作成・更新時期 | 打合せ実施時、記録内容の訂正時 |
| 記載する内容 | 議題、確認結果、決定事項、未決事項、担当、期限 |
| 記載しない内容 | 不要な個人情報、秘密情報、個人的な感想 |
| 関連文書 | [打合せ記録テンプレート](../../templates/meeting-note-template.md) |
| 関連Issue | [#1](https://github.com/EU0207/concert-reception-system/issues/1) |
| 状態 | Draft |
| 承認情報 | 未承認 |

## ファイルの作成方法

1. 打合せ記録テンプレートを複製します。
2. ファイル名を `YYYY-MM-DD-topic.md` の形式にします。
3. 事実、決定事項、未決事項を分けて記載します。
4. 要件や作業が発生した場合は、該当する文書またはIssueへ反映します。

打合せ記録には、必要以上の氏名、連絡先、来場者情報を記載しないでください。
