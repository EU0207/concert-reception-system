# ADR-000: 判断内容を表す短いタイトル

## この文書について

| 項目 | 内容 |
|---|---|
| 目的 | 重要な技術上・設計上の判断と理由を記録する |
| 主な読者 | 開発担当者、将来の保守担当者 |
| 作成・更新時期 | 重要な判断を提案・決定・置換する時 |
| 記載する内容 | 背景、判断基準、候補、比較、決定、影響 |
| 記載しない内容 | 個人的な感想、判断に関係しない調査結果 |
| 関連文書 | 関連する要件・設計文書へのリンク |
| 関連Issue | `#Issue番号` |
| ADR状態 | Proposed |
| 決定日 | 未決定 |

## 判断基準

- 要件を満たせること
- 運用と保守が可能であること
- セキュリティ上の問題がないこと
- 費用と導入負担が許容できること
