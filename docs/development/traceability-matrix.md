# トレーサビリティ表

## この文書について

| 項目 | 内容 |
|---|---|
| 目的 | 要件と受入条件、将来の設計・テストとの対応を追跡する |
| 主な読者 | 開発担当者、確認担当者 |
| 作成・更新時期 | 要件定義工程以降、関連成果物の追加・変更時 |
| 記載する内容 | 要件IDと関連する成果物のID・リンク |
| 記載しない内容 | 要件や設計そのものの詳細説明 |

## 対応表

要件の確定後に行を追加します。設計書とテスト仕様書の列は、それぞれの工程で追加・更新します。

| 要件ID | 要件概要 | 受入条件ID | 設計ID・文書 | テストケースID | 状態 |
|---|---|---|---|---|---|
| 未登録 | 要件確定後に記載 | 未登録 | 未登録 | 未登録 | Draft |

## 更新ルール

- 要件を追加または変更した時は、対応する受入条件を確認します。
- 設計を作成した時は、対象となる要件IDを記載します。
- テストケースを作成した時は、確認対象となる要件IDと受入条件IDを記載します。
- 要件を廃止する場合も行を削除せず、状態と置き換え先を記録します。
