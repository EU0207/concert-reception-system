# POC-005 実機確認手順

## この文書について

| 項目 | 内容 |
|---|---|
| 目的 | IT開発経験がない確認担当者が、3台で座席表と画像の完全オフライン表示を同じ手順で確認する |
| 対象 | iPhone 17、iPhone 13 mini、Galaxy Z Fold8 |
| 前提 | [POC-005開始承認依頼書](poc-005-approval-request.md) |
| 状態 | In Review |

## 先に知っておくこと

- 使うのは架空の500席と、実在会場ではない5枚の合成画像だけである。
- Firebase ConsoleやGoogleアカウントの操作は不要である。
- Wi-Fiで一度準備した後、機内モードでWi-Fiと携帯回線の両方を切って確認する。
- 結果JSONを共有するまで、「端末データ削除」は実行しない。
- OS更新、端末初期化、他サイトの履歴削除は行わない。

## 端末ごとの確認

1. 端末を充電し、空き容量不足の警告が出ていないことを確認する。
2. PCに表示されたPOC-005用QRコードを標準カメラで読み、URLを開く。
3. Wi-Fi接続中であることを確認し、「座席と画像を事前取得」を1回押す。
4. 「準備完了」「500件」「5枚」と表示されるまで待つ。失敗した場合は連打せず、表示メッセージを知らせる。
5. 1階・2階、席番号の昇順・降順、現在席の変更、5枚の画像を操作する。
6. 「画像なしの代替一覧を確認」を押し、画像なしでも階・区画・列・席番号・現在席が分かることを確認する。
7. 機内モードをオンにする。iPhoneはコントロールセンター、Androidはクイック設定でWi-Fiもオフになっていることを確認する。
8. ページを更新し、座席表、現在席、5画像が表示されることを確認する。
9. ブラウザーを一度終了して開き直し、同じ内容が表示されることを確認する。
10. iPhone 13 miniでは、ボタンと入力欄を拡大せず操作できることを確認する。
11. Galaxy Z Fold8では、外側画面、内側画面、開閉後を確認し、現在席と準備完了が失われないことを確認する。
12. 機内モードを元に戻す。
13. 「実機確認結果」で端末とOS版を選び、確認できた項目だけにチェックを入れる。
14. 「匿名結果JSONを保存」を押し、`FAKE-P005-device-result-...json`をこの会話へ添付する。

## 終了時の削除

3台分の結果確認後、開発担当者から削除案内が出た時だけ実行する。

1. 画面下部へ移動し、確認欄へ「削除」と入力する。
2. 「この端末のPOC-005データを削除」を押す。
3. 「削除しました」と表示され、上部が「再度事前取得が必要」になったことを確認する。
4. 端末のダウンロードから`FAKE-P005-`で始まる結果JSONだけを削除する。
5. 開発担当者の案内に従い、この確認URLのサイトデータだけを削除する。他サイトや全履歴は削除しない。

## 困った場合

- 画像取得が途中で止まった: Wi-Fiを確認し、表示されたエラー全文を共有する。
- 機内モードでもオンラインと出る: Wi-Fiが再接続していないか確認する。表示だけで判断せず、ページ更新後に座席と画像が出るかを確認する。
- 画像が出ない: 代替一覧で現在席が分かるか確認し、画像なしとして結果へ記録する。
- JSONの場所が分からない: iPhoneは「ファイル」アプリのダウンロード、Androidは「Files」等のダウンロードを確認する。
