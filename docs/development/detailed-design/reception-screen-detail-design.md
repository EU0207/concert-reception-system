## DD-89-01 画面と戻り先

| 画面・操作 | 遷移先と条件 |
|---|---|
| D-01受付ホーム→D-02専用カメラ | 公演と本人・端末、準備状態を確認して起動。公演名・日付を固定表示し、別公演のカメラを自動起動しない |
| D-02の戻る矢印・ブラウザーの戻る | D-01へ。読取り・カメラとライトを先に停止する。履歴上の外部ページを戻り先として使わない |
| D-02→D-05会場席確認 | 結果表示・保存処理中でない場合だけ直接移動。閲覧権限を確認し、カメラとライトを停止。戻る時はD-02で復帰検査から始める |
| D-02内の連絡ベル | 読取りを一時停止して重ね表示。閉じても未確認受付結果があれば結果確認を優先。D-06へ移る場合はカメラとライトを停止 |
| P-12会場席確認→P-04会場席編集 | P-12は既存の確認画面へ付与するID。主担当・代理の準備導線で使い、編集権限を拡大しない。未保存離脱確認を経てP-12へ戻る |
| D-05等から許可された席編集 | 遷移元の会場確認画面ID・公演と区画を保持し、P-04から同じ確認画面へ戻る。当日の編集範囲はDD-91を維持 |
| 直接リンク・再起動で有効な戻り先なし | R-01担当公演ホーム。別公演や任意URLを戻り先に採用しない |

戻り先はアプリ内の許可済み画面IDと現在公演に限定する。戻る矢印のある画面には同じ戻り先を示すパンくずを置く。例は「受付ホーム ＞ QR受付」「会場席確認 ＞ 会場席編集」。パンくずからの移動も通常の戻ると同じ停止・未保存確認を通し、上位画面名だけを見せて別の画面へ移動しない。

D-03は独立した戻る先ではなく、未確認結果の前面表示とする。背景の矢印・パンくず、会場席確認とベルは操作不可。「次へ」で確認を完了するまで、背面へフォーカスを移さない。戻る操作を受けても結果を確認済みにせず、未確認参照を保持して安全に離脱できる。再入場時は同じ結果を優先表示する。

## DD-89-02 読取りと結果の状態

| 状態 | 許可・停止と次の状態 |
|---|---|
| 復帰確認中 | カメラ読取り停止。#92から保存済み結果・保存状態と排他所有を取得。現在認可・準備状態の検査後だけ待機へ |
| 読取り待機 | 有効なカメラ世代と所有権の下で1件のQRを受け付ける。QR検出時点で直ちに追加フレームの判定を停止 |
| 判定・端末保存中 | 他のQR・背面操作を止める。#112の資格判定と#92の保存結果を待ち、保存前には成功を表示しない |
| 結果表示中 | 同じresultId・eventIdの結果を前面表示。「端末保存済み・共有待ち」と「共有先で受領済み」を区別。結果を閉じただけでイベントを作らない |
| 次へ確認中 | #92へ同じ結果IDの確認を要求。確認参照の保存完了まで追加読取りを止め、失敗なら同じ結果を保持 |
| 再開待機 | 結果の終了表示が完了してから500ms待つ。現在画面・カメラ世代、未確認結果なしと所有権を再確認して待機へ |
| 中断・ロック | 失効、排他喪失と端末保存不能はカメラ停止。理由と管理者確認・紙受付への導線を表示。状態不明を未記録と断定しない |

再開の500ms待機は連打でも1回だけ開始する。途中の画面遷移・バックグラウンド化、ベル表示とロックでタイマーを無効化する。戻った時に古いタイマーがカメラを再開させない。再開待機中の同じQRは新しいイベントへ変換せず、待機へ戻った後の再読取りは通常の受付済み判定に渡す。

結果の見出し・記号と文章を併用し、成功・再読取り・対象外や要確認を色だけで区別しない。カメラを暗くし、画面の大半を覆う前面領域へ結果と「次へ」を置く。見出しへフォーカスを移して結果を通知し、閉じた後は有効な受付操作へ戻す。結果本文を短時間で自動消去しない。

表示・終了アニメーションは各160msを基準とする。動きを減らす設定ではアニメーションを省略しても、追加読取り停止と終了後500msの待機を維持する。アニメーション完了通知が来ない場合も、結果の確認状態を省略して読取りを再開しない。

### #92との受渡し

画面は公演ID・端末IDと現在の受付セッションを指定して、復帰状態を要求する。返却は「確認中」「未確認結果あり」「未確認結果なし」「保存利用不可／所有権なし」を区別する。未確認結果には固定したresultIdと必要な表示情報、eventIdがある場合は同じIDと送信状態を含める。QR生データや購入者名を診断ログ・URLに出さない。

「次へ」は結果IDを指定し、同じIDの確認完了を待つ。別の結果の参照を消さず、応答不明なら照会して再確認する。画面再描画・同期完了だけで確認済みにしない。#92がイベント・キューと未確認結果の保存、複数タブの排他・連番を設計し、#233が本書の画面へ接続する。#89の承認だけでは#92や製品保存の実行合格としない。

## DD-89-03 カメラ・ライトと異常時

カメラを起動する要求には世代IDを付ける。画面離脱後に遅れて成功した要求は、その映像を採用せず停止する。結果表示中・ベル表示中は読取りだけを止め、映像を継続する場合も新しい受付を始めない。結果表示中のライトは直前の状態を維持できる。

画面離脱、映像停止とバックグラウンド移行では、読取りコールバックと再開タイマーを止めて消灯を要求し、その成否にかかわらず映像トラックを停止する。復帰時は消灯状態から能力・権限と受付状態を再確認する。前回の点灯やカメラ許可を理由に無条件で読取りを始めない。

| 異常・条件 | 表示と操作 |
|---|---|
| カメラ権限拒否・映像取得不能 | 設定方法と再試行を表示し、確認コードによる管理者対応へ案内。一般受付に管理者の確定権限を加えない |
| ライト非対応 | 点灯ボタン自体を出さない。対応時だけ「ライトを点ける／消す」と現在状態を表示 |
| 消灯・ライト制御失敗 | 端末側の操作を案内し、カメラ停止は継続。読取り可能な状態での点灯失敗だけで受付全体を中止しない |
| カメラ喪失・端末ロック | 読取りを止め、復帰確認から再開。保存済み結果や未受領イベントを消さない |
| 保存不能・状態不明 | 「受付状態を確認しています」または具体的な保存エラー。成功も未記録も断定せず管理者・紙受付へ |

通信アイコンは形と文字で接続・切断・確認中を区別する。アイコンを押した時は状態・未送信件数と保存先を示す。オンライン復帰の成立条件は#110と正式RTDB契約を使い、接続表示だけで失効・更新確認を飛ばさない。

## DD-89-04 会場写真・座席表と編集の離脱

会場写真は区画に対応する確定画像版を使う。画像と座席キャンバスのパン・倍率は別に保持し、移動・ズームは端末内の表示操作だけとする。確定版の取得と表示には#105の共通表示を使い、閲覧で席構成・番号や割当を変更しない。

PCはドラッグとスクロール、スマートフォンはスワイプで上下左右へ移動できるようにする。ドラッグ終端を席選択・構成変更として発火させない。拡大縮小と方向移動のボタン・キーボード操作も用意し、写真と席の全領域へ到達できるようにする。固定した設定欄・主要操作はキャンバスと一緒に画面外へ流さない。

座席表は「標準倍率で左上へ」と「選択席へ戻る」を分ける。選択席が存在する場合だけ同じseatIdを中央へ表示し、なければ理由を表示する。写真では独立した倍率・位置を戻す。区画・画像版が変われば、その対象の有効範囲へ表示位置を調整し、古い別区画の選択席を当てはめない。

画像の取得失敗・未準備ではエラーを示して座席一覧へ切り替えられるようにし、別区画の画像で代用しない。座席表の取得版が混在する場合は不完全な席図を確定版として出さず、同じ版の再取得を案内する。一般受付へは現在席・座席表示名と必要な状態だけを渡し、購入者名と管理履歴を混ぜない。

P-04等の未保存離脱では「保存して移動／保存せず移動／編集を続ける」を表示する。端末下書き・共有・確定の保存先はDD-91とCONF-074を使い、単に戻るために共有確定しない。保存失敗・版競合時は入力を保持して移動しない。パンくず・ブラウザーの戻るにも同じ条件を適用する。通常の未保存確認に重大操作の独立2回確認を一律適用しない。
