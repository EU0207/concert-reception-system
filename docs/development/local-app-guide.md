## 起動

Node.js 24.19.0以上、pnpm 11.25.0を使用する。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm setup:local
pnpm build
pnpm preview
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)で架空の公演を開く。終了は `Ctrl+C`。

- `setup:local` はGit管理外の評価設定を明示作成する。外部Firebaseへ接続しない。
- 起動設定がない場合は安全停止する。PWAとオフライン起動はビルド版で確認する。
- スマートフォンは信頼済みHTTPSが必要。HTTPのLANアドレスでは製品開発版は起動しない。静的UIモックとは条件が異なる。

設定の境界と実機確認の残条件は[共通アプリ基盤の詳細設計](detailed-design/app-foundation-detail-design.md)を参照する。

## 本人認証画面の見本

`http://127.0.0.1:4173/#/login`、または「このアプリについて」→「ログイン画面を確認」から開く。実際のGoogleログイン・メール送信は行わない。

Googleボタン、または架空の `fictional@example.invalid` と `Fictional123` で表示を確認する。メール確認・再認証とログアウトを試せる。「確認状況を更新」は見本では確認済み表示へ進む簡略動作であり、実認証の完了を意味しない。入力画面へ戻るにはログアウトする。

通常SDKとの結合確認と残条件は[本人認証画面の記録](technical-validation/authentication-ui-results.md)を参照する。実認証後の業務認可と端末準備への接続は後続作業である。

## スタッフ・端末の見本

架空公演を開き「スタッフ・端末」を選ぶ。既定の確認サーバーでは `http://127.0.0.1:4173/#/events/00000000-0000-4000-8000-000000000001/devices` で開ける。

承認待ちの端末で承認・取消しを試し、「最新の状態を確認」で更新する。停止・停止解除と廃止も確認できる。主担当の廃止では、同じ主担当の準備済み別端末がなければ拒否する。

外部通信しない見本であり、実際の端末登録や権限は変えない。画面を開き直すと架空台帳は初期化する。未送信件数は未取得と表示し、承認を事前準備完了とは扱わない。[SDKの試験と残条件](technical-validation/device-management-ui-results.md)を参照する。

## 会場席の作成・編集

「会場席の編集」から操作する。

| 操作 | 手順・条件 |
|---|---|
| 区画の作成 | 「区画を追加」で行列数と採番を指定。キャンバスでセルを選び「席に」などを試す |
| 寸法・採番の変更 | 「席の設定」から変更し、「設定を反映」で変更前後を確認する |
| 外周への追加 | 「行・列を追加」で既存番号を保ったまま追加する |
| 区画の切替 | 「表示する区画」で選択する |
| 構成全体の移動 | 「席の設定」→「席構成全体を1マスずらす」。移動先側の端がすべて「未」の場合に移動できる。前後を確認し「移動を反映」後、下書き保存する。番号は維持する |
| 個別の番号変更 | 未割当席を1つ選び「席番号を変更」から編集する |
| 個別の位置変更 | 未割当席を選び「席の位置を変更」後、キャンバスで相手を押す。未割当席なら交換、「未」「空間」なら移動。移動元は「空間」になる。前後を確認して反映する |

下書きの編集では変更理由の入力は不要。

**表示位置と倍率**

- ドラッグ・スワイプと方向ボタンで移動する。キャンバスにフォーカスがあるときは矢印キーも使える。
- 「＋」「−」で拡大縮小する。
- 「標準倍率で左上へ」「選択席へ戻る」で表示位置を戻す。

## 保存・復元

「下書き保存」→「保存する」で、このブラウザーに暗号化して保存する。同じ公演を開き直し、変更と保存時刻を確認する。

**「下書きを共有」と「確定保存」はローカルの試験操作。** 実際の共有・確定保存が完成したものとして扱わない。通常SDKで確認した共有基盤と未接続の画面は[共有保存・別端末復元の記録](technical-validation/shared-seat-draft-results.md)で区別する。

## 会場画像

「会場画像を表示／隠す」→「画像を追加」から、架空の会場画像を選ぶ。

### 入力と保存

- PNG／JPEG・WebP・HEIC／HEIFに対応。元写真は20MB以下、保存後は各1MB以下、公演全体で最大5枚。
- 保存前に「原寸で確認」で文字と向きを確認。「左回り」「右回り」で90度ずつ調整する。
- 「端末に保存する」で保存する。開き直しても保存した向きを表示する。「閉じる」で取り消した回転は保存しない。
- 取消し・失敗では元の登録画像を保持する。画像は端末内の確認用で、共有先へ送信しない。

### 表示と区画との対応

- どの区画でも全画像を閲覧できる。画像の前後移動では区画を変更しない。
- 「この区画で最初に表示する画像（任意）」を設定したら下書き保存する。区画切替時にその画像を表示する。未設定なら表示中の画像を維持する。
- 画像の倍率と座席キャンバスの倍率は独立する。

### 倍率と画像内の移動

- 「原寸」は保存した画像の100%。「＋」で最大400%まで拡大できる。
- 「＋」「−」は100%・125%・150%などの固定段階で切り替わる。2本指の開閉では細かく調整でき、途中の倍率からボタンを押すと隣の固定段階へ移る。
- 「＋」「−」「原寸」は現在見ている位置を保つ。拡大後はドラッグ・スクロールで画像内を移動する。
- 「全体表示」で画像全体が収まる配置へ戻る。倍率欄には実倍率だけを表示する。

### 差替え・削除

「画像を差し替え」で表示中の画像を更新する。「画像を削除」では画像番号と使用中の区画数を確認し、「削除する」で端末の確認用画像を削除する。共有先の画像と座席は削除しない。

確認済み範囲と残条件は[会場画像の実装・試験記録](technical-validation/venue-image-results.md)を参照する。
