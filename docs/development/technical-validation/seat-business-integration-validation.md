### 保存境界と採用理由

本人セッションを試験投入する方式から、本人Authによる通常発行へ進めた。登録済み端末・初期役割は前提投入として区別する。

開始・停止・終了は、controlとpublicStatus、履歴と共通版の4件を同時確定する。共通版のcontrol・commit・receptionを進める。構成候補の期待版が古くなるため、開始前の候補を再確認なしで公開できない。停止して準備表示へ戻しても初回開始時刻と版を戻さない。

静的参照予算は状態遷移7＋1＋3＋4＝15、構成公開8＋6＋6＝20。キャッシュ減算なし。Rulesの式評価数・請求量は未測定。[比較コード](../../../poc/GD91-60/tests/budgets.mjs)と[ADR-007](../decisions/ADR-007-seat-edit-commit-boundary.md#公演状態と完成候補の共通版gd91-60)へ追跡する。構成公開へ追加の業務条件を接続するときは再算定する。

Emulatorの同時要求では、送信順をそろえても409 ABORTEDのロック待ちと403のRules内部参照エラーにより双方未確定になる場合を観測した。J04は全正本と両操作IDを照会し、明示再操作後の1件確定まで確認する。403をすべて再送する方針にはしない。一般の権限拒否を競合扱いにせず、SDKのエラー分類・案内は後続で確認する。

**制約：最終10回のうち7回が双方未確定となり、照会後の明示再操作で成功した。** 3回は初回から1件が成功。データ不変と二重確定拒否を確認した結果であり、円滑に保存できることの合格ではない。REST・Emulatorの限定結果のため、SDKでの競合・エラー分類を次に優先確認する。

## GD91-61 SDKの競合・エラーと明示再操作

2026-10-11、GD91-60と同じRules・通常発行トークンを使い、Node.js上のFirebase Web SDK 12.18.0で[14件](../../../poc/GD91-61/artifacts/sdk-summary.json)が合格。実行前後23ソースハッシュ一致。旧47件は今回再実行・加算していない。[README](../../../poc/GD91-61/README.md)へ手順を集約する。

### SDK保存の判定と制約

| 範囲 | 結果・限界 |
|---|---|
| S01～06・12 | 構成3件と状態4件を通常保存。同一操作の結果を返し、異なるイベントと旧版を拒否。部分保存・失効で正本不変。権限拒否をアプリケーションで自動再送しない |
| S07・08 | 対照試験。通信停止API後でもトランザクションは送信できた。通常バッチはオフライン待機後に自動送信された。通信停止APIやバッチ待機を未送信の保証にしない |
| S09・10・13・14 | 別SDKインスタンスで同じIDを照会。照会不能は不在と区別。明示オフライン制御ではコールバック0。gRPC UNAVAILABLE注入で3試行終了・書込み0。障害解除後の照会で不在と正本不変を確認し、明示操作後に確定 |
| S11 | 同時要求10回、初回成功は最大1件。今回の双方未確定は0回。SDKコールバックの再実行は4回の競合で観測。全10回の最終成功は1件だけで、負けた旧案は再計算せず拒否。実環境で毎回成功する保証ではない |

操作IDと期待版、送信案をコールバックの外で固定する。保存時は操作履歴を先に読み、既存イベントとの一致を確認する。未確定なら共通版を照合し、一括確定する。SDK内部の最大3試行と、失敗終了後の利用者による再操作を区別する。回復イベントから保存を開始する処理はない。

permission-deniedだけでは認可失効とRules検査・内部参照失敗を区別できない。無条件再送せず、結果照会へ進む。照会も拒否・通信失敗なら「不明」のまま案を保持し、別IDで再発行しない。古い版は最新状態を表示して再確認する。画面案内の実装は未実施。

S09は保存成功後に戻り値を採用せず、別インスタンスで照会する試験。実際の応答パケット喪失・プロセス再起動ではない。履歴イベントの内容照合を確認したが、送信内容全体の永続ハッシュ・暗号化したIndexedDB操作記録との接続は残る。HTTP/2プロキシのgRPCエラー注入を実回線断の合格へ読み替えない。

静的Rules参照はGD91-60の構成公開20・状態遷移15を維持。トランザクションの明示読取りと再試行により通信が増えるため、請求量・最大構成は#167で別測定する。[ADR-007](../decisions/ADR-007-seat-edit-commit-boundary.md#sdkの明示保存と結果照会gd91-61)へ比較と理由を記録する。
