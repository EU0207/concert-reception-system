## 結論と対象範囲

2026-11-26、開発者からレビューOKとmain統合の指示を受領した。今回の承認は設定画面と記載した通常SDKの確認範囲であり、実際の任命・端末追加準備と各業務の受入を代替しない。

既に臨時管理者として任命された本人の現在設定を表示し、固定9項目のON/OFFと有効期間を編集できる。変更前後を確認し、固定入力を暗号化保存してから、既存の通常SDKで役割版・プロファイルと結果・監査を一体確定する。権限範囲や保存形式を変更しない。

開始条件は#110の認可・権限設定基盤、承認済みDD-98とPR #309・312のmain統合である。#111-Aの段階受渡しを使用する。実認証後の業務画面や各端末の追加準備は親#263へ残し、設定のONだけで業務を許可しない。

## 表示と操作

設定一覧と変更前後は、ONを緑の○、OFFを赤の×で表示する。記号の横に許可・不許可の文字は添えず、読み上げ用のON/OFFだけを保持する。設定値と保存処理は変更しない。

| 操作 | 画面・保存側の扱い |
|---|---|
| 一覧 | 現在認可を検査し、臨時管理者だけを表示する。現在役割版に対応するプロファイルが欠損・不正なら変更を許可せず、全ONを補充しない |
| 9項目の編集 | DD-98の固定9項目だけを表示する。未知キー・禁止操作を追加する入力欄は設けない |
| 有効期間 | 端末のタイムゾーンと設定可能期間を明示する。変更しない日時の元のミリ秒を維持し、サーバーは役割期間とスタッフ期限を再検査する |
| 確認・取消し | 保存前に変更前後を確認する。編集中や確認画面のキャンセルは書き込まない |
| 全OFF | 全項目OFFでも臨時管理者の役割を維持する。一般受付の共通操作と保存済み記録を削除しない |
| すべて選択／解除 | 個別項目の上にチェック欄を置く。全選択・未選択・一部選択を同期し、編集中の9項目だけを一括変更する。確認・保存前には送信しない |
| 全解除後の保存 | 9項目すべてOFFの通常設定を新しい版で保存する。専用の設定取消しボタンは設けず、過去の取消し済み設定と既存APIの扱いは維持する |
| 下部の操作 | 編集ダイアログの一番下は変更内容の確認とキャンセルだけにする。チェック項目・期間は中央部分でスクロールし、下部操作を表示し続ける |
| 保存後 | 最新認可・設定を自動取得し、完了案内を閉じると現在設定へ戻る。取得失敗と変更失敗を区別する |

通常の編集や確認画面の取消しで監査を追加しない。重要な確定・取消しの監査は、既存の認可監査契約で一体保存する。独立2回確認を設定変更へ追加しない。

## 応答不明・失効と再起動

固定入力は既存の`authorizationOperations`へ端末の既存鍵で暗号化保存する。新しい鍵を自動生成して古い入力を読み捨てない。保存が失敗したら送信しない。

- 応答不明では新しい変更を重ねず、既知の同じIDで結果照会する。照会だけでは再送しない。
- 未確定なら同じ入力の明示再試行、または未確定案の取消しへ進む。後者は現在の設定を変更しない終端結果であり、確定済み設定の全OFFとは区別する。
- 再起動後は保存済み入力と結果を照合し、自動再送しない。対象版が変わった入力は保持して再送を止める。
- 通信断や本人・端末の失効、認証期限と対象の期間境界では表示とダイアログを閉じる。遅い応答で復活させない。

役割・設定の版が変わっても、対象端末の準備済み版を勝手に進めない。各端末の追加準備と業務操作の許可判定は後続へ接続する。

## 確認範囲

| ID | 確認内容 |
|---|---|

| TEMP313-B02 | 一括選択の3状態、取消しでの元設定保持と、全解除・全選択を確認後に保存する操作 |
| TEMP313-B03 | 不正な期間の拒否と編集取消しでの元設定保持 |
| TEMP313-B04 | 確定応答喪失を結果照会だけで回収し、再送しない |
| TEMP313-B05 | 再表示後に同じIDで一回だけ確定する |
| TEMP313-B06 | 未確定案の取消しで現在設定を維持し、欠損設定を拒否する |
| TEMP313-B07 | 役割版が変わった入力を保持して再送しない |
| TEMP313-B08 | 認証期限で設定と編集中のダイアログを閉じる |
| TEMP313-B09 | 確定後の取得失敗を区別し、再取得で二重送信しない |
| TEMP313-B10 | 日時入力が00秒を省略しても、変更していない有効期間の元のミリ秒を保持する |
| TEMP313-S01 | 通常SDKで変更・全解除・全選択と監査を一体確定。端末内保存失敗では未送信。対象の準備済み版を進めない |
| TEMP313-S02 | 応答喪失・未送信を実際の再読み込み後に復号し、同じIDの再試行と未確定案の取消しを確認 |
| TEMP313-S03 | 承認・役割準備済みの一般受付でも設定一覧の取得を拒否 |

共通の架空本人・端末登録fixtureを端末管理の試験から抽出し、同じ登録経路を使用する。実際の招待・任命と対象端末の完全準備を試験投入で代替しない。Firebase Rulesは変更せず、既存のDD98-R01～03も回帰確認する。

型検査・Rules照合とビルド、単体・既存モック250件が合格した。PC・スマートフォン幅のブラウザー全180件（当時の本画面18件を含む）、通常SDK10件（本画面6件・既存端末管理4件）と、既存RulesのDD98-R01～03の3件が合格した。PC・スマートフォン幅の一覧と編集ダイアログを目視確認した。対象実機と実Google、全512設定の各業務画面への結合は今回の完了範囲ではない。

最終確認で、`datetime-local`が00秒を省略すると未変更の期間を再解釈してしまう問題を検出した。入力欄へ代入した後の正規化値を比較基準にして、未変更の元のミリ秒を維持するよう修正した。TEMP313-B10でその境界を固定時刻で確認する。

日時正規化と入力欄配置の最終修正後は、新画面のブラウザー20件と通常SDK6件を再実行して合格した。変更していない有効期間が不当に拒否されず、開始・終了のミリ秒が保持されることを確認した。

一括選択と下部操作の整理後も、ビルド・新画面20件と通常SDK6件が合格した。一部選択の中間状態、全解除後のキャンセルで元設定が残ること、通常の全OFF設定から全選択へ保存できることを確認した。PC・スマートフォン幅で、一括チェックが個別項目の上、確認・キャンセルが下部に表示されることも確認した。

## PC確認と後続

ローカルの公演の「スタッフ・端末」から「臨時管理者の権限設定」を開く。直接URLは配信ポートに応じて次の形とする。

`http://127.0.0.1:4174/#/events/00000000-0000-4000-8000-000000000001/permissions`

見本は外部通信せず、開き直すと架空の設定へ戻る。暗号化保存・再起動回収の製品経路は通常SDKのローカル結合試験で確認する。カード配置と配色は確認済みモックのスタッフ管理を参考にし、モックにない固定9項目はDD-98に合わせて追加した。

1. 9項目と有効期間を編集し、確認画面でキャンセルして元に戻る。
2. 1項目をOFFで保存し、完了案内を閉じて反映を確認する。
3. 個別項目の上の一括チェックで全解除し、確認・保存して全項目×を確認する。全選択も同じ手順で保存する。

後続は親#263の招待・任命、管理者の追加端末関連付けと実認証後の業務接続である。#261・263で追加準備へ接続し、#233・234・106等で各業務のON/OFFを結合する。対象実機の寿命と全体の無料受入は#220へ残す。
