# GD91-150 削除前の登録端末・受領履歴確認

状態：In Review。削除処理より先に、登録台帳と受領連番を順番に確認する隔離候補。通常の削除機能の合格ではない。

対象はv2で取り込んだ通常締め済み公演。現在認可と直近の本人再認証を検査し、確認中は業務更新を止める。登録端末ごとに連番を走査し、隔離記録の未照合で停止する。未照合があれば削除せず確認を取り消し、通常の照合後に新しい確認を始める。確認済みの状態でも、本文を削除する許可は追加しない。

台帳外の持込記録、個人の完全削除と原本・端末・外部バックアップの回収は別の残条件。台帳内の確認完了を全複製の削除完了へ扱わない。
