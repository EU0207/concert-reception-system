# GD91-109 最大入力と容量境界

状態：Draft。読者：開発者・設計担当者・テスト担当者。#167の完了条件1・4の残条件を対象とする。本番実装と外部接続は行わない。

## 目的と確認順

GD91-108の通常人数試験に対し、長い入力と非席セルを増やした構成を比較する。既存Rulesの文字列上限を用い、区画名100、列名64と表示席番64を確認する。確保用途100と追加理由200も載せる。単位は今回のRulesが使う文字列長であり、業務上のUnicode文字数の確定とは区別する。

4,096セル・16区画は検証候補であり、製品上限ではない。現在の取得側の既定予算は256片×16セルである。保存側との共通上限、追加編集と保持・再開の結果を揃えてから判定する。

通常管理経路で構成を保存・公開し、再取得で全セルの値を照合する。上限超過の直接要求が拒否され、公開済みの座席表が変わらないことを確認する。試験後に全拒否Rulesと空の試行根を確認する。

## 中間結果

初回600人は4,096セルの保存・公開・再取得を通過した。その後の拒否試験で、新規世代の試験データに検査用メタデータが不足して停止した。後処理は確認済み。全境界の合格としては扱わず、試験データを修正して再試行する。

無料枠全体と最大入力候補の採用は未判定。#167の完了条件を維持する。
