# GD91-105 区画操作の保存接続

状態：Draft。読者：開発者・設計担当者・テスト担当者。#167の隔離検証。PR #206は2026-10-15に承認・main統合済み。本番実装と方式採用は含まない。

今回の単位は区画新設・改名と舞台位置変更の保存、再取得と保持。部分送信・対象外変更と競合を拒否し、同じ候補で既存経路を回帰確認する。計算や入力接続だけでは区切らず、この範囲全体の検証または具体的な判断制約まで継続する。

## データと処理の流れ

名前と舞台位置は席データから分離した区画表示情報へ保存する。表示版と業務版を同時に進め、取得時に確定構成へ適用する。セルと席番号の複製を避け、割当・QRと緊急印を維持する。

区画新設は新ID・未セルで候補を作り、既存区画を双方向に検査して一体公開する。既存の区画名と舞台位置、余白スライドも最新状態で保持する。初回受付開始後の新規区画作成は許可しない。

追加末尾の自動採番、区画の削除・並替えと帳票の生成は今回の対象外。端末状態はRAMで、実IndexedDBと全業務無料成立は残る。外部Firebase・課金・公開と3,000人試験は行わない。
