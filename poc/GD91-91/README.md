[model.mjs](model.mjs)は変更対象の現在資格3項目を操作結果へ記録する。氏名は複写しない。[snapshot-rules.mjs](snapshot-rules.mjs)で受付用行と同時に検査し、部分送信・別資格の記録を拒否する。

[sdk-adapter.mjs](sdk-adapter.mjs)は同一IDの結果と固定案を比較し、変更先も復元して照合する。後から現在券が変わっても、元の操作の資格で確認する。表示名は変更不能という現候補の前提を使う。名前訂正の接続時は、過去の表示名との照合方式を再評価する。

- [SDK8群](artifacts/validate-summary.json)：通常登録・席設定、旧操作の照会と別内容の拒否。一括割当後の発券・不参加と復帰も比較した。
- [Edge5群](artifacts/recovery-summary.json)：1,000席と固定案を暗号化IndexedDBへ保存し、ブラウザー終了後に復元した。確定後のREST応答接続を実際に切断。別端末がQRを再発行した後も、元のIDを照会して再書込み0件だった。

ブラウザー内の認証持続・実機とSDK内部の通信断は未検証。全業務・無料成立と本番採用は未完了。外部接続は行っていない。
