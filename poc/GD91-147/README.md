# GD91-147 正式候補パスでの移行Rules

状態：In Review。TECH-DD91-118-Aの同じブラウザー取込を、詳細設計の保存先パスへ接続するローカル検証。

## 制約と変更理由

GD91-146のRulesを`environments/{environment}/performances/{performance}`へそのまま展開すると13,545,464 Bとなり、Emulatorの10,485,760 B上限へ拒否された。短いPoCパスでの受理を正式パスへ流用しない。

現在の役割・端末・セッションと15分以内の本人認証を維持し、主担当専用の入口に必要な式へ整理した。owner以外の役割列挙とprovider分岐を、owner・Googleの条件へ展開する。文字列と正規表現の内部は保持し、式の空白と環境変数名を縮める。保存先の階層や環境分離を変更しない。

許可の本人と固定目録の本人の一致は、許可の作成・更新時に検査する。目録は更新不能である。この不変条件で保証済みの一致を各末端へ重複展開しない。生成時に前提の検査式が存在することも確認する。元の通常Rulesにない制御項目は追加しない。

最終Rulesは9,619,854 Bで受理された。上限との差は865,906 B。実サービスでの配備可否、今後の項目追加と全形式移行の成立を保証する値ではない。
