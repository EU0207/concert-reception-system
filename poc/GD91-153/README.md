状態：In Review。152の生成Rulesはローカル上限まで2,939 Bしか余裕がないため、認可を保つ縮約を確認した。保存先の階層を変えず、管理者用の述語だけを整理する。

## 方式と条件の対応

| 元の条件 | 整理後 | 維持する境界 |
|---|---|---|
| 有効な4役割のどれか、かつ主担当か代理 | 主担当または代理を先に判定 | 一時管理者と受付担当を管理者へ昇格しない |
| 管理者はGoogle、他役割はpassword | 管理者専用の述語ではGoogle方式を要求 | 役割と認証方式の組合せを維持 |
| 本人・端末とセッションの現在条件 | 同じ版・結合と有効期限を検査 | 停止・失効と不整合を拒否。更新時の直近本人再認証も維持 |

引用・正規表現の内側を除く空白も削る。主担当専用の取込許可は、引用外の空白を除いて元の式と同一であることを確認する。クライアントが申告した役割や保存済みの判定結果へ認可を移さない。
