# GD91-144 旧Bytes画像からRTDB画像への限定変換

状態：In Review。#168の117-Aに従うローカルEmulator検証。

POC-006の単体Bytes形式をFirestoreから取得し、既存126のRTDB Rulesへ接続する。公開中の画像5枠・各1,000,000 Bを対象とし、移行元の版とバンクをRAMの変換計画へ記録する。新しい公開操作IDを使い、公開前のバンク保存と公開結果を再取得して照合する。

```text
node poc/GD91-144/run-local.mjs
```

7群が合格。未公開バンク保存後の中断と公開応答の喪失から再開し、各枠の公開操作は1件だけである。端末停止・役割停止で拒否し、別の有効端末の取得は継続する。旧Firestoreの原本を変更せず、5,000,000 Bの一致を確認した。

初回は役割期限とセッション期限を同じ「現在+1時間」で別々に作り、後者が数ms後になって発行を拒否された。期限の前提を修正し再実行した。[初回](artifacts/first-local-failure.json)と[最終](artifacts/local-summary.json)を区別する。双方で全拒否Rules、空試行データとAuth 0件を確認した。

限界：元画像はowner前提投入。PNGとしての実デコードではなくBytes・サイズとハッシュの検証である。旧7片・5MB形式は1MBへ自動縮小せず拒否した。非公開バンク・画像履歴全体の変換と、端末へ永続保存した再開計画は未確認。全領域の有効化ゲートや本番移行ツールの合格ではない。追加外部試行0件。
