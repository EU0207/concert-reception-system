# GD91-120 暗号化通信のローカル計測

状態：Draft。読者：開発者・設計担当者・テスト担当者。#167条件4の中間証拠。本番実装は行わない。

## 結論

600／1,000人の架空データを6環境で取得し、TLSを含む通信量を確認した。初回取得・差分受信に加え、明示的な再取得と新しい6環境での再開を計測した。無料成立の判定は残る。

| ローカルTLS下り通信 | 600人 | 1,000人 |
|---|---:|---:|
| 6環境の初回取得 | 53,928,826 B | 73,174,912 B |
| 全員分の差分受信 | 2,429,442 B | 4,049,514 B |
| 同じ環境での明示再取得 | 53,902,408 B | 73,148,670 B |
| 新しい6環境での再開 | 55,913,512 B | 76,484,142 B |
| 接続終了までの合計 | 166,174,856 B | 226,857,928 B |

各工程の合算と全体値には、工程境界後の終了通信の差がある。[監査結果](artifacts/audit-summary.json)に差分を残す。1MBは1,000,000 Bとして比較する。

## 測った範囲

[sdk-local.mjs](sdk-local.mjs)はFirebase SDK 12.18.0を使用する。16区画・4,096セルの構成に、最大長の架空プロフィールを加える。差分は600／1,000件を各環境へ届け、再開時の重複通知が0件であることを確認する。

これは通信負荷用の専用データであり、一般受付へプロフィール全体の読取りを許可する設計ではない。専用Rulesは認証済み読取りだけを許し、業務権限の合格証拠にはしない。結果の`registrationAndTicketsSeeded`は履歴上の区分名で、通常登録・発券を実行した意味ではない。この試験で投入するのは構成・プロフィールと受付イベントである。

[tls-proxy.mjs](tls-proxy.mjs)がローカルEmulatorの前で暗号化し、公開Socketカウンターで下り・上りを計測する。通信本文やトークンは計測結果へ残さない。証明書と秘密鍵はGit管理外へ一時作成し、終了時に削除する。信頼する証明書は子プロセスだけに追加し、検証を無効化しない。

## 確認と制約

- 通信計測器は10条件が合格。空応答・大きな応答と拒否応答を含み、接続再利用・再接続と証明書検証も確認した。
- SDKは4／600／1,000人の各4工程が合格。試験後の全拒否Rulesと空試行根を確認した。Googleログインと外部Firebase接続は行っていない。
- 同じSDK環境の`goOffline`→`goOnline`はタイムアウトし、未確認。新しい環境での再開を代替の証拠と混同しない。[停止記録](artifacts/first-reconnect-failure.json)を保持する。

初回のTLS計測はCLIのEmulator接続設定によって迂回された。子プロセスの設定を外し、通信0 Bを合格にしない検査を追加した。直接HTTPS計測の初期方式ではNodeが異常終了した。TCP接続完了後にTLSを開始する公開Agent APIの方式へ修正し、3条件を再確認した。これらの停止は合格へ数えない。

ローカル証明書での測定であり、実サービスの証明書・課金メーターを測った結果ではない。TCP/IPヘッダーと再送は含まない。GD91-115の業務本文へ単純加算するとSDK分が重複するため、業務工程の暗号化通信は別途接続して評価する。初期化・終了前提の代用と、追加操作・保持の予算も残る。
