割当と券参照は架空の固定入力として保持を確認する。発券・QR検証処理、正式認可と競合検出は含まない。緊急理由も呼出元の検証用条件であり、初回本番受付開始の正当性を確認するものではない。画面・印刷と実機試験は未実施。
