# GD91-113 観測時刻と受付認可の分離

状態：In Review。読者：開発者・設計担当者・テスト担当者。2026-10-16、開発者がTECH-DD91-106-Aを承認。同じPR #214でGD91-112の分析から継続する。本番アプリ実装は行っていない。外部107-Aは2026-10-17に承認範囲内の1試行を完了。

## 変更

端末観測時刻が未来という理由だけでは受付受領を拒否しない。元の観測時刻を保持し、サーバー受領時刻と区別する。認可・公演状態と回収許可はサーバー条件を維持する。

[generate.mjs](generate.mjs)が変更するのは、通常受付と隔離受領の観測時刻検査2か所だけ。値は0以上・8,640,000,000,000,000以下の整数ミリ秒とし、[ECMAScriptのTimeClip](https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-timeclip)で扱える範囲に限定する。型不正と欠損は拒否する。受領時刻はサーバーのnowと一致する条件を維持し、端末による値の偽造を拒否する。

認証期限と役割失効の式は変更しない。停止後は通常受付を拒否し、隔離受領しても受付実績へ自動反映しない。締め後は管理者が発行した有効な回収許可が必要で、期限・公演状態版と連番範囲を検査する。これらの式は端末観測時刻を許可根拠にしていない。
