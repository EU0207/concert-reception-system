# GD91-76 取得データの暗号化保存と再起動

状態：In Review。#167の同じ検証単位を継続する隔離PoC。[容量検証記録](../../docs/development/technical-validation/seat-capacity-validation.md#gd91-76-再起動後の暗号化再利用)へ結果を集約する。本番実装・方式採用ではない。

## 対象と結果

GD91-75の取得契約へ、ブラウザーのIndexedDBによる暗号化保存を接続する。600人・1,000人で別々の利用者6名・端末6個のセッションを使い、ブラウザー終了後の再取得を並列実行する。Edgeの隔離保存プロファイルは1つで、端末ID別の保存領域を使う。6台の実機・本番SDKによる試験とは区別する。

前提データはownerで投入した取得専用の架空データ。通常登録・確定の500人制限を解消した証拠ではない。3,000人は試験しない。

| 人数 | 初回の要求／直接文書数（1クライアント） | 再起動後の要求／直接文書数（1クライアント） | 暗号文サイズの目安 |
|---|---:|---:|---:|
| 600 | 805／2,408 | 204／606 | 約0.60 MB |
| 1,000 | 1,341／4,008 | 338／1,006 | 約1.00 MB |

原データは[cache-summary.json](artifacts/cache-summary.json)。人数別2件と異常系13件を記録する。既存V2・GD91-75の合格件数へ加算しない。サイズは端末内の暗号文であり、Firestore文書の1MiB上限の評価値ではない。

鍵欠損・AAD取り違え、未対応形式と容量ガードのブラウザー保存専用4件は[storage-summary.json](artifacts/storage-summary.json)に分ける。Rulesや実機の合格へ加算しない。

## 処理と安全性

| 処理 | 実装と確認 |
|---|---|
| 現在の認可 | `cached-reader.mjs`が本人用・端末用パスと公開索引を既存Rulesへまとめて照会する。利用者・端末の取り違えと失効では、端末データを復号する前に停止する |
| 復元と版照合 | 公開索引の確認後に暗号文を復号し、世代付きの構成・版付きの表示名を再利用。受付状態は最新取得し、最後に公開索引を照合する |
| 鍵と暗号 | `cache-store.mjs`で公演・端末別の非抽出AES-GCM 256ビットCryptoKeyを永続保存。AADへ環境・公演、利用者・端末と鍵版を結び付ける。保存ごとに新しい96ビットIVを使う。追加パスフレーズは使わない |
| 保存成功 | 暗号化後のIndexedDBトランザクション完了で成功とする。版の比較により競合上書きを拒否する。途中中断では直前の暗号文を保持し、変更のない再取得では再保存しない |
| 停止と障害 | 復号済み値を破棄する。鍵と暗号文は消さない。通信失敗でも復元表示を解放せず、自動再送しない。停止解除後は最新認可を確認して元の鍵・データを再利用する |

6つの認証クライアントのREST処理はNodeで実行し、暗号化保存は実際のEdgeで実行する。ブラウザーのFirestore要求は0件。アプリ全体をブラウザーへ接続した試験ではない。

本番では既存の端末暗号化アダプターから公演・端末鍵を受け取る。[承認済み鍵方針](../../docs/development/basic-design/security-privacy-design.md#bd-05-04-端末内暗号化と鍵管理)に合わせ、PoCでは専用DBに同方式の鍵を生成する。固定の架空環境ID・鍵版1を本番設定と扱わない。保存形式と鍵版の移行は未検証。

保存量ガードはPoCの10,000項目・平文JSON 8MiBで、製品の人数・セル上限ではない。物理的な容量不足・電源断は注入しておらず、IndexedDBの中断で直前データの保持を確認する。iPhone・Androidと完全オフライン起動は未確認。サーバー確認不能時に使える承認済みオフライン権限は後続#110で接続する。

## 費用評価への接続

6クライアントの実際の要求数へ、GD91-75と同じRules依存の机上モデルを適用する。本人・端末の確認2文書を、公開索引の初回取得と同じ要求へまとめる。再起動後6クライアントのモデルは600人13,356読取り、1,000人22,176読取り。安全係数2では26,712／44,352となる。

当日の受付送信・再入場と差分受信、急な変更は未算入。全業務の無料成立・運用上限は未判定。前日の取得を暗号化して再利用する経路を確認した証拠であり、実際に日付をまたいだ認証期限更新や紙切替を検証した結果ではない。
