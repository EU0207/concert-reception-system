# GD91-121 通常業務のTLS通信と総無料予算

状態：Draft。読者：開発者・設計担当者・テスト担当者。#167条件4、DD91-T70・71へ追跡する。本番実装は行わない。

## 現在地

4／600人の登録から通常締めまでがローカルTLS経由で合格。1,000人は実行中。人数別の通信と保存の評価をまとめるまで、無料成立・#167完了とは扱わない。

| 通常業務の計測 | 600人 |
|---|---:|
| 通常REST要求 | 14,722 |
| TLS下り／上り | 44,615,291／28,333,326 B |
| 締め後のJSON | 10,046,283 B |
| 登録端末／SDK環境 | 8／6 |

326件の現行ソースを照合し、全員の名前・来場状態と終了後の全拒否・空試行根を確認した。[4／600人の中間監査](artifacts/partial-audit-summary.json)。

## 計測方法

[generate.mjs](generate.mjs)はGD91-115の通常業務試験へ最新GD91-116 Rulesを接続する。業務内容を変更せず、[bootstrap.mjs](bootstrap.mjs)が通常RESTだけをTLS中継へ送る。6 SDK環境も同じ中継を使う。通常RESTの全要求が中継されたことを件数で照合する。

登録・一括割当と券操作を行い、受付を6環境へ通知する。全8登録端末を照合して通常締めと初回実績を生成し、名前・来場状態を維持する。構成の初期公開も通常権限で実行する。初期台帳と終了状態の投入は試験用前提であり、通常業務の合格へ加算しない。

ownerの前提投入とEmulator保守は計測中継を迂回する。これらが代用する初期化・公演終了の本番通信を0と評価せず、予算へ別の予約量を置く。Authの通信も計測器の対象外である。

同じ端末環境でのスナップショット3回と、受信カーソルを維持した再購読を含む。SDKの`goOffline`→`goOnline`による同じ接続環境の復帰とは区別する。後者の未確認はGD91-120に残す。

## 予算モデルの仮定

[budget-model.mjs](budget-model.mjs)で実測と予約量を分ける。通常SDKを含む実測にGD91-115の本文を重ねて加えない。[scenarios.mjs](scenarios.mjs)の入力は比較用であり、承認済みの製品上限ではない。

| 区分 | 比較に置く量 |
|---|---|
| 通常業務 | 今回のTLS実測。保守的に上りも加える |
| 追加の構成保存 | 最大構成の保存10回。通常権限のGD91-117要求数を使用し、保存本文・スナップショットと6環境取得を加える |
| 全件再取得 | GD91-120の6環境・最大プロフィールを含む取得を追加2組。一般受付の実際の権限範囲より広い負荷データである |
| その他の追加業務 | 50回×4MiBの予約。1回4MiBが十分という実測証明ではない |
| バックアップ | 締め後JSON相当を2回。前・締め後の必須取得へ対応する本文モデル。実装時の取得要求数は未確認 |
| 初期化・終了と認証 | 締め後JSONの4倍を予約。前提投入を通常経路で実測した意味ではない |
| 通信付加量 | 通常RESTと追加構成保存の各要求に8,192 Bを予約。既存通信量へ意図的に重ねる余裕であり、公式上限ではない |
| 他の利用 | 月間通信1GB、保存100MBを別に予約 |

公演ごとの計算に既存の安全係数2を適用する。1／4公演の比較、構成保存20回、通信付加量8倍の感度比較も出す。保存は締め後JSONへ保護中の構成2世代を加え、20世代を保持する比較も残す。未解決参照が増えたときに強制削除して予算へ合わせない。

無料枠は[公式料金](https://firebase.google.com/pricing)と[通信算定](https://firebase.google.com/docs/database/usage/billing)を2026-10-17に再確認した。RTDBの比較値は保存1GB・下り10GB／月。拒否応答や暗号化の付加量も見込む。日付変更による通信枠の回復を案内しない。他サービスの枠へ合算・振替しない。

上の予約量は未検証の仮定であり、比較結果が枠内でも全業務の無料保証には使わない。完成時に通常経路を実装して再計測し、無料条件の表示を更新する。1,000人を超える利用の無料維持は保証対象外とする。

## 再現と証拠

```text
node poc/GD91-121/generate.mjs
node poc/GD91-121/run-local.mjs 4 600 1000
node poc/GD91-121/audit.mjs
node poc/GD91-121/budget-test.mjs
node poc/GD91-121/scenarios.mjs
```

8GiBのEmulatorで人数別に隔離実行する。TLS証明書はGit管理外へ一時作成し終了時に削除する。Googleログイン・認証設定変更は不要。初回の試験接続で見つかった参照先不一致は[停止記録](artifacts/setup-failures.json)に保持し、合格へ数えない。

自動PoCの結果であり、実機受入は後続タスクへ追跡する。容量と方式の最終採用は#168のゲートを維持する。
