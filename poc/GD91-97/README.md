状態：In Review。読者：開発者・設計担当者・テスト担当者。#167のGD91-96候補を、ローカルと外部で同じ手順へ結ぶ。外部実行はTECH-DD91-089-Aとして承認済み。

[common-cases.mjs](common-cases.mjs)は2人を通常登録・一括割当し、通常のQR生成から受付へ接続する。一般受付端末2個がSDKで現行目録・座席配置と公開用行を取得し、参照付き受付を送る。セッション期限後の目録取得・既存購読を、有効端末と比較する。データは架空の来場者2人・4セルだけで、600人・1,000人試験や全業務の合格へ換算しない。

[共通ローカル結果](artifacts/common-local-summary.json)は4群合格。最大536ノード、準備・後処理を除く76呼出し。期限切れ端末の新規受信0件、有効端末は各1件。目録の新規REST・SDK取得も拒否し、未送信キュー・世代参照は残した。型の違う過去候補の外部合格は流用しない。
