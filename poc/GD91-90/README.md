[bulk-rules.mjs](bulk-rules.mjs)は準備中の未割当者と空席だけを対象とし、正逆参照・表示と受付用行を同時に検査する。別人への便乗・部分更新と重複割当を拒否する。全通常操作に構成世代・構成版と公演管理版を記録し、旧版で作った案を拒否する。

[model.mjs](model.mjs)は対象者だけから受付用行を作る。[投影比較](artifacts/projection-comparison-summary.json)は600人・1,000人で旧計算と同じ結果となり、元データを変更しなかった。全体を複製する処理を省いた。JSON入力バイト数を複製量の比較指標とし、実メモリー使用量や速度の保証とはしない。GD91-89のJavaヒープ不足と、この端末側の改善は別の事実である。

[整合性試験](artifacts/validate-summary.json)の8群は部分送信と重複、古い版と同時操作を確認した。4人・6SDK環境の予備試験は合格したが、人数別合格には加えない。Java上限8GiBでEmulatorを再起動し、600人の登録後に一括送信を行ったところ、検証用HTTP要求の20秒期限で中断した。全拒否・空ルートを確認した。応答不明を未確定と断定せず、次の比較では同一操作IDの結果を照会する。

初期一括割当以外の公演中の追加・訂正、全端末停止と保持回収の合同化は未確認。#167の全条件・無料枠と本番採用は未完了。外部試験・課金と公開設定変更は含めない。
