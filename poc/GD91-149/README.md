## 処理と範囲

4人の通常登録・受付と締めを使い、元データ→v2変換後→移行先の訂正前→訂正後で比較する。本文保存と訂正は通常トークンを使う。全体再計算用の移行先読取りはローカルEmulator ownerによる診断であり、管理画面の広い取得権限を追加したものではない。
