# GD91-100 締め後回収と実績訂正の保全

状態：Draft。読者：開発者・設計担当者・テスト担当者。#167の保持・回収条件を同じ検証単位で継続する隔離PoC。本番実装・外部試行は行わない。

ADR-004・CONF-049とBD-08に従い、例外締め後に発見した端末の記録を自動受領しない。管理者の明示照合と、締め後の実績訂正を通常受付から分ける。失われた端末の受領・物理削除を完了扱いにしない。

## 基準候補の診断

`closed-baseline.mjs`はGD91-99のRulesと自動隔離送信を変更せずに使う。公演締め・紛失端末状態は前提投入し、締め後の未送信記録が自動で隔離受領されるかを確認する。業務上の許可を示す試験ではない。

- なし。承認済みの例外締め・発見後の自動取込禁止と、理由付き公演後訂正を維持する。
