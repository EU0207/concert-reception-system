# GD91-08: 座席表全体のスライド計算

状態：In Review。読者：開発者、設計担当者、テスト担当者。
Issue #101の隔離検証。結果・主要試験は[詳細設計](../../docs/development/detailed-design/seat-management-detail-design.md#gd91-08-全体スライドの計算検証)へ集約する。本番実装として使用しない。

```powershell
node poc/GD91-08/tests/slide.mjs
```

既存Node.jsと標準ライブラリーだけを使用し、GD91-07の検証用型・検査を再利用する。追加依存・Firebase接続はない。旧PoCのソースと証拠は変更しない。

同一区画を上下左右へ1行／1列ずらす。移動先の外周は全セルが未の場合だけ許可し、未セルを反対側へ移す。採番列が移る方向では列設定のindexも追従する。全体が未なら変更なしを返す。

計算入力の複製上で変更し、認可・当日判定と確定保存は行わない。`initialNumbered`はGD91-07の検証用状態であり、確定版や認可の証跡ではない。`maxCells`も検証用の確保予算であり、製品上限ではない。割当・券QR参照と受付参照は架空入力の保持だけを確認する。正式な券QR・受付処理の結合試験を代替しない。

Rulesでの不正要求拒否、保存競合・応答喪失と途中公開防止は未検証。SDK・IndexedDB、画面・帳票と実機試験も未実施。実行前後のソースハッシュが一致した場合だけ証拠を作成する。
