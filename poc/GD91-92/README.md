# GD91-92 基準世代と未解決操作の参照保護

| 項目 | 内容 |
|---|---|
| 状態 | Draft |
| 読者 | 開発者、設計担当者、テスト担当者 |
| 目的 | #167の未解決案を、旧世代の回収と応答照会へ接続する |
| 前提 | GD91-91を引き継ぐ。demo Emulatorと隔離Edgeの架空データのみ |
| 結論 | 管理端末の参照11群・確認済み版4群と暗号化再開5群が合格。全業務・無料成立は未完了 |

基準を取得する前に[references.mjs](references.mjs)で世代を保護する。固定案を端末へ保存してから、操作IDと期待する確定版を参照へ予約する。[reference-rules.mjs](reference-rules.mjs)はその予約と書込みを結ぶ。参照なし・他端末の参照と未予約の要求を拒否する。

結果照会で内容一致を確認するか、確定版・構成版の進行で元の要求が通らないと確認してから予約を解く。予約を解いても下書きの基準は保護したままにする。明示的な破棄・移行後に世代参照を解除する。時刻だけの自動解除はなく、失効・喪失した端末の参照は残る。

- [参照11群](artifacts/validate-summary.json)：未解決解除と他端末による解除を拒否。競合後の古い要求を拒否し、全参照解除後だけ上限付き回収を再開できた。操作結果は保持する。
- [確認済み版4群](artifacts/known-reference-summary.json)：正常時は確認済み参照版を使い、古い版を拒否する。実際の確定応答を照合し、偽の応答では未確定の保護を解除できない。
- [Edge5群](artifacts/recovery-summary.json)：暗号化した固定案・参照IDを復元し、実REST応答切断と別端末のQR更新後も再書込み0件。権限失効時は案・参照を残す。

公演制御版だけの変更と受付キューの参照、共有候補の保持は継続対象。ブラウザー内の認証持続・実機、全端末停止と全業務の予算も未確認。外部接続・本番採用は含めない。

**依頼者に確認してください**

- なし。承認済みの保持・復旧方針を維持する。
